## Key Bindings

| Key Binding | Description                |
| ----------- | -------------------------- |
| `SPC-f-s`   | save file                  |
| `SPC-b-f`   | format buffer              |
| `SPC g s`   | `:Git status`              |
| `SPC g A`   | `:Git add .`               |
| `SPC g c`   | `:Git commit`              |
| `SPC '`     | open float terminal window |
| `SPC p l`   | list recent projects       |
| `SPC f r`   | list recent files          |
| `SPC Tab`   | same as `:b#`              |
